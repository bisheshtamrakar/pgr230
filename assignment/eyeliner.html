eyeliner

Eye liner is a cosmetic product used to define and enhance the eyes. It is typically applied along the lash line to create a defined look and can be used to create various eye looks, from subtle to dramatic.

Types of Eyeliner


  • Pencil Eyeliner: This type is easy to apply and blend, making it ideal for beginners. It provides a soft, smudged look and is available in various shades.

  • Gel Eyeliner: Gel eyeliner offers a more precise application and long-lasting wear. It is often used for creating sharp, defined lines.

  • Liquid Eyeliner: Liquid eyeliner provides the most precise application and can be used to create bold, dramatic looks. It dries quickly and offers long-lasting wear.
